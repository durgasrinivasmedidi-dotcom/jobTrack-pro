# JobTrack Pro 🚀

JobTrack Pro is a web-based job application tracking system.

## Features

- Add job applications
- View applications
- Edit applications
- Delete applications
- Search by company or role
- Filter applications by status
- Dashboard statistics
- MySQL database
- Responsive design

## Technologies

- Python
- Flask
- MySQL
- HTML
- CSS
- Git
- GitHub

## Application Status

- Applied
- Interview
- Selected
- Rejected
